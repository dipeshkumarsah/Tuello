# External services and costs

Rule: everything is open source and self-hostable, or a hosted service with no monthly fee.
Anything paid sits behind an interface with a free adapter. Keep this table current.

| Service                 | Used for                                                         | How it is used now                                   | Free allowance                                                                   | Price beyond                                                                          | Free alternative / adapter                       |
| ----------------------- | ---------------------------------------------------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------ |
| PostgreSQL 16           | Primary database                                                 | Container                                            | Open source                                                                      | —                                                                                     | —                                                |
| PgBouncer               | Connection pooling                                               | Container                                            | Open source                                                                      | —                                                                                     | —                                                |
| Valkey 8                | Queues, cache, sessions, rate limits                             | Container                                            | Open source (BSD)                                                                | —                                                                                     | —                                                |
| Caddy                   | Reverse proxy, automatic TLS, on-demand certs for custom domains | Container                                            | Open source                                                                      | —                                                                                     | Coolify's proxy                                  |

| Coolify                 | Deploy on git push, env management                               | Self-hosted                                          | Open source                                                                      | —                                                                                     | Plain docker compose                             |
| Cloudflare (free plan)  | DNS, CDN, DDoS protection                                        | Planned                                              | Free plan                                                                        | Paid plans optional                                                                   | Any DNS provider                                 |
| Cloudflare R2           | Object storage (production)                                      | S3 API via `StorageService`                          | 10 GB storage, 1M class A + 10M class B ops / month, **no egress fees**          | $0.015/GB-month storage; $4.50 per million class A ops; $0.36 per million class B ops | MinIO / Garage / SeaweedFS (self-hosted, S3 API) |

Not used yet (later phases): Stripe Connect and Stripe Billing (no monthly fee; per-transaction
pricing), SMS (off by default; pay-per-message adapter), geocoding/routing (Photon + Valhalla
self-hosted, or a hosted free quota), Google Calendar API and Microsoft Graph (free within
quotas).
